# Agent Janitor & Anti-Distraction Plugin

Prevents AI coding agents from falling into the "Agent Distraction" trap (side-quests on stale TODOs, unprompted bug investigations, and scope creep).

## Includes
- **Skill:** `anti-distraction` (auditing, pruning, and masking)
- **Rule:** `rules/AGENTS.md` (active scope enforcement across all sessions)
- **MCP Server:** `agent-janitor` (tools for `audit_codebase`, `clean_dead_ends`, `mask_triggers`)
