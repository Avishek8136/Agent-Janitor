# Agent-Janitor Skill for Agensi.io

This package contains the **Agent-Janitor** skill, MCP configuration templates, and setup instructions for AI coding agents.

## Package Contents
* **`SKILL.md`**: The root skill definition instructing coding agents when and how to invoke Agent-Janitor's audit, pruning, and masking tools.
* **`SETUP.md`**: Complete setup instructions covering Python installation, MCP server configuration, and invocation prompts.
* **`config_templates/`**: Ready-to-use MCP configuration snippets for Claude Code / Claude Desktop, Cursor, Windsurf, and generic MCP clients.
